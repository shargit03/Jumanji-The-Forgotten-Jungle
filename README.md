# Jumanji: The Forgotten Jungle

A text-based adventure game developed in Java where players explore a mysterious jungle, make choices, collect items, and overcome challenges to progress through the story.

## Features

- Interactive text-based gameplay
- Multiple locations to explore
- Inventory management system
- Companion and item interactions
- Object-Oriented Programming principles

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## How to Run

1. Compile all Java files:

```bash
javac *.java
```

2. Run the game:

```bash
java Game
```
